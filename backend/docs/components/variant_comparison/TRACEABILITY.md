# Variant comparison traceability

The component directly supports the case comparison scenario:

- compare at least two saved project variants;
- use the same calculation period/time grid;
- expose changed configuration parameters;
- compare service availability and outage characteristics;
- compare route characteristics;
- preserve failure/resilience information useful for explaining design trade-offs.

Recommendations are intentionally outside this component. `variant_comparison`
provides the factual comparison vector from which an application/UI or later
recommendation component can justify a choice without hiding the underlying results.
