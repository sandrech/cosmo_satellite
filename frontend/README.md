# Frontend MVP

Интерфейс запускается независимо от backend и получает данные через
`SimulationGateway`. По умолчанию используется `MockSimulationGateway`.
`HttpSimulationGateway` уже имеет тот же контракт и станет точкой подключения
API после реализации расчётного сервиса.

## Запуск

```powershell
cd frontend
npm.cmd install
npm.cmd run dev
```

Открыть: http://127.0.0.1:5173

## Что доступно

- вращение и масштабирование 3D-глобуса;
- переключение 3D/2D;
- выбор C65/C70/C72;
- выбор спутника на глобусе и в аутлайнере;
- иерархический аутлайнер: группы, плоскости и отдельные объекты;
- независимое сворачивание ветвей и управление видимостью через «глаз»;
- включение и выключение слоёв;
- timeline и playback;
- экран настройки проекта и загрузка JSON;
- экран устойчивости;
- сравнение двух вариантов;
- выгрузка демонстрационного JSON.

Жёлтая метка `DEMO · MOCK DATA` явно показывает, что backend ещё не подключён.

## Качество глобуса

Основная текстура загружается из ArcGIS World Imagery. Если сервис недоступен,
компонент автоматически переключается на OSM. Для чёткости Cesium использует
resolutionScale до 2×, FXAA и уменьшенный maximumScreenSpaceError. Яркость,
контраст, насыщенность и gamma задаются на одном ImageryLayer и могут быть
позднее вынесены в пользовательские настройки.
